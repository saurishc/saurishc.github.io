# Classical gas
A classical gas is a system of classical identical particles. Classical particles have the following important properties.
- They are _distinguishable_, i.e., we can, in principle, follow each particle as the system evolves.
- Any number of particles can occupy a given single particle state.
- There is no restriction if two particles in the system are interchanged. (We will see that this is not true for quantum particles.)
